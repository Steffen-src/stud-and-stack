STUD & STACK — Parts Shop Showcase 1.3.0
DEUTSCH
Eigenständige lokale Shop-Oberfläche mit 97 Beispiel-Lots und selbst erstellten SVG-Teilegrafiken. Deutsch/Englisch, Teilenummernsuche mit Vorschlägen, Kategorie/Farbe/Zustand/Preis-Filter, Sortierung, Listen-/Rasteransicht, Merkliste, Produktvarianten, Mengenwahl, Warenkorb und dreistufiger Vorschau-Checkout mit Versand, Zahlungswahl, Prüfung und Bestätigung.
Keine echten Bestellungen, Zahlungen, E-Mails oder Bestandsreservierungen. Keine WooCommerce-, Bricqer- oder BrickLink-Anbindung. Das große Inventar des ursprünglichen Kundenbriefings wurde nicht importiert. Preise/Bestände/Versandlaufzeiten sind Beispieldaten.
WORDPRESS: ZIP über Plugins > Installieren > Plugin hochladen installieren/aktivieren. WordPress >=6.0, PHP >=7.4. Neue Seite mit [studstack_shop] veröffentlichen, lokal öffnen. Die Shop-Seite verwendet eine eigene vollständige Ansicht ohne Theme-Header/-Footer. Einstellungen > StudStack: Markenname, Akzent, Standardsprache. Nur auf der ausdrücklich gewählten Seite aktiv. Kein WooCommerce erforderlich. Plugin vollständig entfernen zum Rückbau; Einstellungsoption studstack_options bleibt erhalten.
STATIC: index.html über einen lokalen Webserver öffnen. app.js/style.css/assets gehören zusammen. Keine externen Bild-/Font-Abhängigkeiten. Eigene Produktdaten: specs/colors/categories/dict in app.js austauschen, Asset-Quelle in work/studstack/build_assets.py anpassen. Preise sind ganzzahlige Eurocent. Datenformat nicht für 18.000 Browser-Lots optimiert: produktiver großer Katalog benötigt serverseitige Suche/Pagination und echte Commerce-Integration.
PRIVATSPHÄRE: Nur Sprache, Warenkorb und Merkliste werden im Browser lokal gespeichert (studstack-showcase-v1). Adressdaten nur im Arbeitsspeicher, kein Versand. Keine echten Kundendaten im Vorschauformular eingeben. Keine Schlüssel, Konten oder persönlichen Empfänger enthalten.
BEDIENUNG: Einheitliche Karten-Hover, Tastatur-Fokus, native Dialoge mit Escape, responsive Layouts, reduzierte Bewegung berücksichtigt. Produktgrafiken mit natürlichem 480:320-Verhältnis. Warenkorb und Formular sollten bei Änderungen erneut getestet werden.

ENGLISH
Standalone bilingual parts-shop presentation with 97 sample lots and original scalable SVG illustrations. Search suggestions, category/colour/condition/price filters, sorting, list/grid views, wishlist, variants, quantities, cart and delivery/payment/review/confirmation journey.
Presentation only. No real payments, orders, emails, stock reservations, WooCommerce, Bricqer or BrickLink connection. No imported 500,000-part inventory. Prices, stock and delivery times are illustrative.
WORDPRESS: Install and activate the plugin ZIP. Requires WordPress >=6.0 and PHP >=7.4. Create a page containing [studstack_shop]. That page renders a complete standalone storefront instead of the theme layout. Settings > StudStack configures brand, accent and default language. No WooCommerce dependency. Deactivate to restore normal theme rendering. The studstack_options setting is retained.
STATIC: Serve index.html together with app.js/style.css/assets from a local web server. No external image/font requests. Data and translations live in app.js. Product generator: work/studstack/build_assets.py. Euro prices use integer cents. A production 18,000-lot catalogue requires server-side search/pagination and commerce integration.
PRIVACY: Browser storage keeps cart, wishlist and language only. Addresses remain in memory and are not submitted. Use fictional data. No API keys, payment accounts or fixed customer recipients are included.
ACCESSIBILITY: Consistent hover effects, keyboard focus, native Escape-dismissable dialogs, responsive styles and reduced-motion support. Preserve product image proportions. Test all affected states after changes.
Font: Manrope, SIL OFL; license bundled in assets. Code: GPL-2.0-or-later. Brand is a portfolio working name, not a checked registered trademark.

Version 1.3.0 adds PBR product renders, a redesigned 3D home and orbit/snap studio. See STUDIO-3D-DE-EN.txt and CREATIVE-DE-EN.txt for operation, configuration and limitations.
